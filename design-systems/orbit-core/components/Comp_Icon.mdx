# Comp_Icon — Icon

Thuộc nhóm **hiển thị**. Bộ icon lucide inline SVG stroke currentColor — CẤM icon-font/emoji làm icon.


> **Luật token-only**: mọi giá trị hình thức trỏ token của gói; sửa hình thức → sửa
> `tokens.json` (hoặc thêm 1 dòng `DECISIONS.md` nếu là quyết định mới), không hard-code.


## Giải phẫu

svg stroke currentColor 24-viewbox co qua width/height; không fill, màu kế thừa chữ.

## Trạng thái

default · sending: spinner (loader) · disabled: mờ 0.7 · mặc định: theo quy ước chung của kho · đang gửi: theo quy ước chung của kho · bị vô hiệu: theo quy ước chung của kho

## Token dùng

- `--color-fg`
- `--text-sm`

## Biến thể

- `default` — hình thái chuẩn
- thêm biến thể chỉ khi ≥2 màn dùng thật

## Tiếp cận

- aria-hidden với icon trang trí; icon hành động thì nhãn nằm ở nút

## Không được làm

- Không emoji làm icon
- Không đụng fill — stroke currentColor để kế thừa token màu

## Mã nguồn

<!-- EXPORT: components/ui/icon.tsx -->
```tsx
// Standalone — deps: react, lucide-react
import type { LucideIcon } from "lucide-react"
import { Cake, AlarmClock, BookOpen, Check, Flame, Zap, MessageSquare, House, Users, Plus, Search, Trash2, Pencil, Calendar, Flag, X } from "lucide-react"

const ICONS: Record<string, LucideIcon> = {
  cake: Cake, alarm: AlarmClock, book: BookOpen, check: Check, flame: Flame, zap: Zap,
  msg: MessageSquare, home: House, users: Users, plus: Plus, search: Search,
  trash: Trash2, pencil: Pencil, calendar: Calendar, flag: Flag, x: X,
}

export function Comp_Icon({ name, size = 16, state = "default" }: { name: string; size?: number; state?: "default" | "sending" | "disabled" }) {
  const Cmp = ICONS[name]
  if (!Cmp) return null
  return <Cmp width={size} height={size} aria-hidden className={state === "disabled" ? "opacity-70" : undefined} />
}
```
