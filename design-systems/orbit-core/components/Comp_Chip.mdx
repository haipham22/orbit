# Comp_Chip — Chip

Thuộc nhóm **hiển thị**. Nhãn người/đ STATUS/trạng thái — 4 sắc: neutral/success/warning/danger, height = control-height-sm.


> **Luật token-only**: mọi giá trị hình thức trỏ token của gói; sửa hình thức → sửa
> `tokens.json` (hoặc thêm 1 dòng `DECISIONS.md` nếu là quyết định mới), không hard-code.


## Giải phẫu

pill inline-flex: nhãn + (tuỳ) icon; nền primary-soft hoặc viền trạng thái.

## Trạng thái

default · sending: spinner + 'đang gán…' · disabled: opacity .5 · mặc định: theo quy ước chung của kho · đang gửi: theo quy ước chung của kho · bị vô hiệu: theo quy ước chung của kho

## Token dùng

- `--color-primary-soft`
- `--color-primary`
- `--color-border`
- `--color-success`
- `--color-warning`
- `--color-danger`
- `--color-surface`
- `--radius-full`
- `--control-height-sm`
- `--text-sm`
- `--space-1`
- `--space-3`

## Biến thể

- tone: `neutral` / `success` / `warning` / `danger`

## Tiếp cận

- Focus ring 2px theo `--color-primary` (focus-visible)
- Vùng chạm ≥24px, mobile ≥44 theo control height
- Accessible name qua label/aria khi không có text nhìn thấy

## Không được làm

- Không dùng chip làm nút bấm được
- Không nền đậm + chữ đậm cùng lúc

## Mã nguồn

```tsx
import * as React from "react"
import { cn } from "@/lib/utils"

const fillStyle = (percent: number): React.CSSProperties => ({ width: `${Math.min(percent, 100)}%` })

const tones = {
  neutral: "bg-[var(--color-primary-soft)] text-[var(--color-primary)]",
  success: "bg-[var(--color-surface)] text-[var(--color-success)] border-[var(--color-success)]",
  warning: "bg-[var(--color-surface)] text-[var(--color-warning)] border-[var(--color-warning)]",
  danger: "bg-[var(--color-surface)] text-[var(--color-danger)] border-[var(--color-danger)]",
}

export function Comp_Chip({ tone = "neutral", className, ...props }: React.HTMLAttributes<HTMLSpanElement> & { tone?: keyof typeof tones }) {
  return <span className={cn("inline-flex items-center gap-1 h-[var(--control-height-sm)] px-3 rounded-full border border-[var(--color-border)] text-[length:var(--text-sm)]", tones[tone], className)} {...props} />
}
```
