# Comp_XPBar — XPBar

Thuộc nhóm **hiển thị**. Thanh tiến độ tuần (gamification) — fill --color-primary trên nền primary-soft.


> **Luật token-only**: mọi giá trị hình thức trỏ token của gói; sửa hình thức → sửa
> `tokens.json` (hoặc thêm 1 dòng `DECISIONS.md` nếu là quyết định mới), không hard-code.


## Giải phẫu

track primary-soft + fill đặc primary (mặc định); ĐANG GỬI 2 kiểu qua prop `loading` — `stripe` (default: bar full-width sọc kẹo 45° chạy tại chỗ, từ huong-2) hoặc `slide` (khối đặc bounce qua lại, không teleport). Bên tiêu thụ định nghĩa @keyframes xp-stripe { to { transform: translateX(-64px); } } (span trùm quá 64px cả HAI bên — mọi pha đều phủ kín track; transform = GPU, không flicker như background-position) và track `relative overflow-hidden`. và @keyframes indet { from { transform: translateX(0); } to { transform: translateX(150%); } } (dùng alternate).

## Trạng thái

default · sending: thanh indeterminate — fill vector trượt trong bar, không spinner tròn · disabled: mờ 0.7 · mặc định: theo quy ước chung của kho · đang gửi: theo quy ước chung của kho · bị vô hiệu: theo quy ước chung của kho

## Token dùng

- `--color-primary`
- `--color-primary-soft`
- `--color-border`
- `--radius-full`
- `--space-3`

## Biến thể

- `default` — hình thái chuẩn
- thêm biến thể chỉ khi ≥2 màn dùng thật

## Tiếp cận

- role=progressbar + aria-valuenow/min/max khi biết % (mặc định, disabled); đang gửi chỉ aria-busy (không có % để nói)
- Sọc indeterminate nhìn như 100% — caller thêm caption/mờ để không ai đọc thành xong

## Không được làm

- Không bao giờ animate width bằng JS tay — CSS transition đủ
- Không đổi hue theo %

```tsx
// Standalone — deps: react
// Loading soc = cong thuc striped chuan Bootstrap: tile 16px + shift dung 1 tile -> seamless
//   @keyframes barberpole { from { background-position: 0 0; } to { background-position: 16px 0; } }
//   @keyframes indet { from { transform: translateX(0); } to { transform: translateX(150%); } } — dung alternate (bounce, khong teleport)
import * as React from "react"

const cn = (...c: (string | false | undefined)[]) => c.filter(Boolean).join(" ")

export function Comp_XPBar({ percent = 76, state = "default", loading = "stripe" }: {
  percent?: number; state?: "default" | "sending" | "disabled"; loading?: "stripe" | "slide"
}) {
  const box = (s: string): React.CSSProperties => ({ opacity: s === "disabled" ? 0.7 : 1 })
  return (
    <div className="relative h-3 rounded-full border border-[var(--color-border)] bg-[var(--color-primary-soft)] overflow-hidden" style={box(state)} role="progressbar" aria-valuenow={state === "default" ? Math.min(percent, 100) : undefined} aria-valuemin={0} aria-valuemax={100} aria-busy={state === "sending" || undefined}>
      <span className={cn("block h-full rounded-[inherit]", state === "sending"
          ? loading === "stripe"
            ? "w-full h-full rounded-[inherit] bg-[var(--color-primary)] bg-[image:linear-gradient(45deg,var(--color-primary-soft)_25%,transparent_25%,transparent_50%,var(--color-primary-soft)_50%,var(--color-primary-soft)_75%,transparent_75%,transparent)] bg-[length:16px_16px] animate-[barberpole_1s_linear_infinite]"
            : "w-2/5 animate-[indet_1.3s_ease-in-out_infinite_alternate]"
          : "w-[76%] bg-[var(--color-primary)]")}
        style={state === "default" ? fillStyle(percent) : undefined} />
    </div>
  )
}

const fillStyle = (percent: number): React.CSSProperties => ({ width: `${Math.min(percent, 100)}%` })
```
