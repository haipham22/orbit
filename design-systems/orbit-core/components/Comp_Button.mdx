# Comp_Button — Button

Thuộc nhóm **action**. Nút hành động — variant primary/ghost/danger, size sm/md/lg theo token control.height.


> **Luật token-only**: mọi giá trị hình thức trỏ token của gói; sửa hình thức → sửa
> `tokens.json` (hoặc thêm 1 dòng `DECISIONS.md` nếu là quyết định mới), không hard-code.


## Giải phẫu

inline-flex container → icon slot (svg 16) → label. Chiều cao từ control.height-*, padding ngang từ space-3/4/5 theo size.

## Trạng thái

default: sẵn sàng bấm · sending: mờ 0.8 + spinner, khoá pointer · disabled: mờ 0.7, aria-disabled · mặc định: theo quy ước chung của kho · đang gửi: theo quy ước chung của kho · bị vô hiệu: theo quy ước chung của kho

## Token dùng

- `--color-primary`
- `--color-on-primary`
- `--color-danger`
- `--color-on-danger`
- `--color-border`
- `--color-surface-raised`
- `--color-primary-soft`
- `--color-fg`
- `--radius-sm`
- `--control-height-sm`
- `--control-height-md`
- `--control-height-lg`
- `--space-2`
- `--space-3`
- `--space-4`
- `--space-5`
- `--text-sm`
- `--text-base`
- `--text-lg`

## Biến thể

- variant: `primary` / `ghost` / `danger`
- size: `sm` / `md` / `lg` (control.height-*)
- trạng thái: mặc định / đang gửi / bị vô hiệu

## Tiếp cận

- Nhãn chữ luôn nhìn thấy (icon-only phải có aria-label)
- Đang gửi giữ aria-busy

## Không được làm

- Không đặt cỡ cố định px — luôn dùng control.height-*
- Không đổi màu ngoài token (variant mới = DECISIONS trước)
- Không cắt cụt label (ellipsis chết trên inline-flex) — label dài thì wrap

```tsx
// Standalone — deps: react, @radix-ui/react-slot
import * as React from "react"
import { Slot } from "@radix-ui/react-slot"

const cn = (...c: (string | false | undefined)[]) => c.filter(Boolean).join(" ")

const Spin = () => (
  <span aria-hidden className="inline-block size-4 shrink-0 animate-spin rounded-full border-2 border-current border-t-transparent" />
)

const VARIANTS: Record<string, string> = {
  primary: "bg-[var(--color-primary)] text-[var(--color-on-primary)] hover:brightness-110",
  ghost: "text-[var(--color-primary)] border border-[var(--color-border)] bg-[var(--color-surface-raised)]",
  danger: "bg-[var(--color-danger)] text-[var(--color-on-danger)]",
}

const SIZES: Record<string, string> = {
  sm: "h-[var(--control-height-sm)] px-3 text-[length:var(--text-sm)]",
  md: "h-[var(--control-height-md)] px-4 text-[length:var(--text-base)]",
  lg: "h-[var(--control-height-lg)] px-5 text-[length:var(--text-lg)]",
}

export interface CompButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: keyof typeof VARIANTS
  size?: keyof typeof SIZES
  state?: "default" | "sending" | "disabled"
  asChild?: boolean
}

export const Comp_Button = React.forwardRef<HTMLButtonElement, CompButtonProps>(
  ({ className, variant = "primary", size = "md", state = "default", asChild = false, children, ...props }, ref) => {
    const Comp = asChild ? Slot : "button"
    return (
      <Comp ref={ref}
        aria-busy={state === "sending" || undefined}
        aria-disabled={state !== "default" || undefined}
        className={cn("inline-flex items-center justify-center gap-2 font-semibold rounded-[var(--radius-sm)] transition-[transform,opacity] [&_svg]:size-4",
          VARIANTS[variant], SIZES[size],
          state === "sending" && "opacity-80 pointer-events-none",
          state === "disabled" && "opacity-70 pointer-events-none",
          className)}
        {...props}>
        {state === "sending" ? <Spin /> : null}
        {children}
      </Comp>
    )
  })
Comp_Button.displayName = "Comp_Button"
```
