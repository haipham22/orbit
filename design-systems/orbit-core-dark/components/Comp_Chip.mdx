# Comp_Chip — Chip

Thuộc nhóm **hiển thị**. Nhãn người + trạng thái dữ liệu — mapping chuẩn 5 trạng thái: todo/doing/done/overdue/due-soon (tới hạn).


> **Luật token-only**: mọi giá trị hình thức trỏ token của gói; sửa hình thức → sửa
> `tokens.json` (hoặc thêm 1 dòng `DECISIONS.md` nếu là quyết định mới), không hard-code.


## Giải phẫu

pill inline-flex: nhãn + (tuỳ) icon; nền primary-soft hoặc viền trạng thái.

## Trạng thái

mặc định · đang gửi: spinner + 'đang gán…' · bị vô hiệu: mờ 0.7

## Token dùng

- `--color-primary-soft`
- `--color-primary`
- `--color-border`
- `--color-success`
- `--color-success-soft`
- `--color-warning`
- `--color-warning-soft`
- `--color-danger`
- `--color-on-danger`
- `--color-surface`
- `--color-text-muted`
- `--radius-full`
- `--control-height-sm`
- `--text-sm`
- `--space-1`
- `--space-3`

## Biến thể

- tone: `neutral` / `doing` / `done` / `overdue` / `soon`
- status (mapping chuẩn dữ liệu): `todo`→neutral · `doing`→doing · `done`→done · `overdue`→overdue (nền solid danger) · `due-soon`→soon (tới hạn)

## Tiếp cận

- Focus ring 2px theo `--color-primary` (focus-visible)
- Vùng chạm ≥24px, mobile ≥44 theo control height
- Accessible name qua label/aria khi không có text nhìn thấy

## Không được làm

- Không dùng chip làm nút bấm được
- Không tự sáng tạo màu trạng thái ngoài mapping — thêm trạng thái mới = sửa spec này
- Chip có nút remove: text bọc span `min-width:0 + ellipsis`, nút remove `flex:none` — ellipsis chết trên flex container

```tsx
// Standalone — deps: react
import * as React from "react"

const cn = (...c: (string | false | undefined)[]) => c.filter(Boolean).join(" ")

const TONES: Record<string, string> = {
  neutral: "bg-[var(--color-surface)] text-[var(--color-text-muted)]",
  doing: "bg-[var(--color-primary-soft)] text-[var(--color-primary)]",
  done: "bg-[var(--color-success-soft)] text-[var(--color-success)]",
  overdue: "bg-[var(--color-danger)] text-[var(--color-on-danger)]",
  soon: "bg-[var(--color-warning-soft)] text-[var(--color-warning)]",
}

const STATUS_TONE: Record<string, string> = {
  todo: "neutral", doing: "doing", done: "done", overdue: "overdue", "due-soon": "soon",
}

export function Comp_Chip({ tone = "doing", status, className, ...props }:
  React.HTMLAttributes<HTMLSpanElement> & { tone?: keyof typeof TONES; status?: keyof typeof STATUS_TONE }) {
  const t = status ? STATUS_TONE[status] : tone
  return <span className={cn("inline-flex items-center gap-1 h-[var(--control-height-sm)] px-3 rounded-full border border-[var(--color-border)] text-[length:var(--text-sm)]", TONES[t], className)} {...props} />
}
```
